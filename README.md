## Projetos em Destaque

### 🤖 Instagram Comment Responder
Bot de resposta automática a comentários do Instagram com IA. Responde comentários de forma inteligente, mantendo o tom de voz da marca.

**Tecnologias:** Python, Instagram API, IA/LLM, Docker

🔗 [Repositório](https://github.com/TiagoYancy/instagram-comment-responder)

---

### 💬 WhatsApp Bot
Bot de atendimento ao cliente via WhatsApp com IA. Sistema completo com dashboard, FAQ inteligente e integração com LLM.

**Tecnologias:** Python, WhatsApp API, IA/LLM, Docker, SQLite

🔗 [Repositório](https://github.com/TiagoYancy/whatsapp-bot)

---

### ⚙️ Hermes Agent
Agente IA pessoal para automação de tarefas, gestão de memória e orquestração de skills. Configurado com 266+ skills instaladas via GitHub.

**Tecnologias:** Python, Ollama (llama3.1, qwen2.5), RTX 3060

🔗 [Repositório](https://github.com/TiagoYancy/hermes-agent)

---

### 📦 n8n MCP Server
Servidor MCP para integração com n8n (JSON-RPC via POST). Atualmente offline — VM 104 excluída; backup preservado.

**Tecnologias:** Docker, n8n, MCP, Ollama, Qdrant
